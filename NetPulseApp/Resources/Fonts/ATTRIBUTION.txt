Provenance
----------
This file was extracted from the FontAwesome.Sharp 6.6.0 NuGet package, which
bundles the same official Font Awesome 6 Free faces under the same licence. It
is byte-identical to the font that package shipped, so every glyph renders
exactly as it did before Services\Icons replaced the library.

Why it is here
--------------
FontAwesome.Sharp ships a single assembly serving both WinForms and WPF, and
stores its fonts as a WPF resource container reachable only through a pack URI.
Referencing it therefore pulled PresentationFramework, PresentationCore,
WindowsBase and System.Xaml — 17.6 MB compressed — into a WinForms-only MSIX.
The font is now a plain embedded resource rendered with GDI+.
