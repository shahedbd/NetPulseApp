Press Diagnose and NetPulse checks your Wi-Fi, router, DNS and internet in seconds, then tells you exactly what's wrong and how to fix it: "Your connection is fine, but your DNS is slow — switch to 1.1.1.1." No command line, no jargon.

Every result copies or exports in one click. Dark and light themes, sharp on high-DPI screens, system-tray friendly, and needs no admin rights.

Free. Every tool. No locked features.

## Core features

- One-click Diagnose — checks adapter, router, DNS and internet, then gives a plain-English verdict and the fix
- Live dashboard — latency, jitter, packet loss and an A–F connection quality grade
- Your connection at a glance — local IP, gateway, DNS, public IP, ISP and location
- VPN detected badge
- Internet speed test — download, upload, ping and jitter, saved to history
- Wi-Fi details — signal strength, band, channel, link speed and security type
- Ping — live latency graph, min/avg/max, jitter and loss; continuous or fixed count
- Traceroute — hop-by-hop route with reverse DNS names
- DNS lookup — A, AAAA, MX, TXT, CNAME, NS and SOA records via system, 1.1.1.1, 8.8.8.8 or any server
- Port checker — TCP open/closed/filtered results with common-port presets
- WHOIS — registrar, dates and name servers for any domain or IP (IPv4 and IPv6)
- Subnet calculator — network, broadcast and host ranges for IPv4 and IPv6
- Copy or export any result in one click
- Dark and light themes, high-DPI sharp, system tray support
- Free — every tool, no locked features, no admin rights
